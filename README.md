# Frame & Focus — Image Gallery

A responsive image gallery created for the CodeAlpha Frontend Development internship.

## Technologies
- HTML5 for page structure
- CSS3 for responsive layout, hover effects and transitions
- JavaScript for category filters, lightbox navigation and keyboard controls

## Features
- Responsive photo grid
- Nature, Architecture and Travel category filters
- Lightbox image viewer
- Previous / Next navigation
- Escape and arrow-key support
- Hover effects and smooth transitions

## Run locally
1. Download or extract the project folder.
2. Open `index.html` in a web browser.
3. Internet access is needed to load the online photographs and Google Font.
